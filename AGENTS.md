# AGENTS.md

## Project
Desktop Airbnb listing page clone for the take-home assignment.

## Tech Stack
- React
- TypeScript
- Vite
- CSS

## Guidelines
- Use reusable React components.
- Keep components small and maintainable.
- Match the reference UI closely.
- Avoid unnecessary dependencies.
- Keep gallery data separate from UI components.
- Use semantic HTML and accessible interactive elements.

## Accessibility
- Support keyboard navigation.
- ESC closes dialogs.
- Arrow keys navigate the lightbox.
- Lock background scrolling when overlays are open.
- Manage focus when opening and closing dialogs.

## Gallery
- Support opening the photo tour from hero images.
- Support opening the lightbox from gallery images.
- Support previous/next navigation.
- Preserve smooth transitions.

## AI Development
- AI tools may be used for implementation, debugging, refactoring,
  and code review.
- Review and test all AI-generated code before accepting it.
- Do not copy source code from the reference website or other
  implementations.

## Validation
Before completing a feature:
- Compare against the reference.
- Test mouse interactions.
- Test keyboard interactions.
- Check console errors.
- Verify overlay behavior.
